# Student Performance Analysis System

## Reflection
While developing this Student Performance Analysis System, I encountered a few challenges. The biggest one was understanding how Python handles indentation, as a single misplaced space caused an `IndentationError` that took a while to debug. I also struggled initially with understanding the difference between abstract classes and concrete subclasses, but building the `AIUStudent` and `ScholarshipStudent` classes helped clarify how inheritance and method overriding work in practice. Overall, this project helped me understand how OOP principles like encapsulation, abstraction, and polymorphism come together in a real-world application.

## AI Use Declaration
I used an AI assistant to help me understand OOP concepts (specifically encapsulation and abstract classes) and to debug errors related to indentation, missing files, and Windows Python terminal commands. The final code structure and logic were reviewed and understood by me before submission.
